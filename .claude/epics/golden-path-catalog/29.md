# Task: Set up SQLite + Drizzle ORM

## Description

Add SQLite + Drizzle ORM to the monorepo as the catalog's storage layer, per
ADR 0006. Foundational task for the rest of M2.

## Acceptance Criteria
- [ ] SQLite driver + Drizzle ORM + Drizzle Kit installed (official method;
      record versions/source in a setup note)
- [ ] A `packages/db` (or equivalent) workspace package holds the DB setup
- [ ] Drizzle config + migration command wired into the workspace
- [ ] `.db` files git-ignored; `.env.example` updated if a DB path var is used
- [ ] `pnpm install`, `pnpm lint`, `pnpm build` still pass

## Technical Details

Per ADR 0006: choose the SQLite driver (`better-sqlite3` vs `node:sqlite`) with
an official-docs check. Drizzle for typed schema + migrations. Keep DB code in
its own workspace package so `apps/web` imports a clean module.

## Dependencies
ADR 0006.
