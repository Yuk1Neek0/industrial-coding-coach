# Epic: golden-path-catalog

## Overview

Build the Golden Path Catalog MVP (Milestone 2): a local SQLite store, the
`golden_paths` schema, a typed data-access layer, five seeded Golden Path
entries, and a Catalog UI page in the web app. This is the project's first real
product feature and its first database.

## Architecture Decisions

- **Storage:** local SQLite via Drizzle ORM — ADR 0006.
- **Schema (MVP):** one `golden_paths` table; list-valued fields as JSON columns.
- **Catalog UI:** built via the **v0 round-trip** — page spec + v0 prompt
  authored here, generated by the user in v0, then integrated.
- **No LLM** in M2 — catalog entries are written and reviewed by hand.

## Technical Approach

### Frontend Components

- A **Catalog page** in `apps/web` — list view (all paths) + detail view
  (one path). Built from a page spec via v0, using `packages/ui` (shadcn/ui).

### Backend Services

- SQLite database file; Drizzle schema + migrations; a typed data-access
  module (list all, get by slug) usable server-side by Next.js. No separate
  server process.

### Infrastructure

- Drizzle migration tooling; a version-controlled **seed script** that loads the
  five Golden Path entries. The generated `.db` file is git-ignored.

## Implementation Strategy

001 sets up SQLite + Drizzle (foundational). 002 adds the schema + migration.
003 (data-access layer) and 004 (entries + seed) then run in parallel. 005 (the
Catalog page spec + v0 prompt) can be written from the PRD at any time and ends
in a **hand-off to the user**. 006 integrates the v0 output last.

## Success Criteria (Technical)

- SQLite schema created reproducibly via migration; seed loads 5 entries.
- Data-access layer typed and tested (list all, get by slug).
- Catalog page lists all 5 paths and shows full detail for each.
- Every entry has fit criteria, steps, learning outcomes, rejected
  alternatives, sources, and risks populated.
- `pnpm lint`, `pnpm typecheck`, `pnpm build` pass; CI green.
