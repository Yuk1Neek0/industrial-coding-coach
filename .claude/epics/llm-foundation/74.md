# Task: CI-safe test harness

## Description

Provide the mock SDK client, fixture support, and a client smoke test so
LLM-backed code can be unit-tested deterministically. This is the test strategy
M4 and M5 reuse for their LLM tasks.

## Acceptance Criteria
- [ ] A mock SDK client implementing the injectable client interface, with
      fixture/recorded-response support.
- [ ] A smoke test runs the LLM client wrapper end-to-end against the mock
      client.
- [ ] The full test suite passes with **no** `ANTHROPIC_API_KEY` set.
- [ ] CI makes zero live API calls.
- [ ] The mock harness is exported so M4/M5 epics can import it for their tests.

## Technical Details

Builds directly on the injectable client seam from task 2. Fixtures should be
easy to author so downstream epics can record their own SDK responses.

## Dependencies

Task 2 (LLM client wrapper). Runs in parallel with task 4.

- Size: M
- Hours: 5

- [ ] Code implemented
- [ ] Tests written and passing
- [ ] Code reviewed
