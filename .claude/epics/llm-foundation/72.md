# Task: Install Anthropic SDK + scaffold packages/ai

## Description

Create the new `packages/ai/` workspace package, install the official Anthropic
SDK into it, and add a validated config accessor for the API key. This is the
structural groundwork the LLM client wrapper sits on. ADR 0005 governs the
decision — no ADR is written here.

## Acceptance Criteria
- [ ] `packages/ai/` created with `package.json`, `tsconfig.json`, and Turborepo
      wiring matching the `packages/db` conventions.
- [ ] The official Anthropic SDK is installed into `packages/ai` via its
      official installation method; version pinned.
- [ ] The official install source/URL and version are recorded in a setup note.
- [ ] `.env.example` documents `ANTHROPIC_API_KEY`; `.env` remains git-ignored.
- [ ] A validated config accessor reads `ANTHROPIC_API_KEY` and fails explicitly
      (typed error) when it is absent — no downstream crash.
- [ ] `pnpm install`, `pnpm lint`, `pnpm typecheck`, `pnpm build` pass with the
      new package.

## Technical Details

Follow the official Anthropic SDK documentation for the install method and
versioning — do not record install commands from memory (CLAUDE.md hard rule).
Mirror `packages/db` for package structure and tsconfig. The config accessor is
the single point where the key is read.

## Dependencies

None. First task of the epic. Governed by ADR 0005.
