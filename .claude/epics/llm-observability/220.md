# Task: Deterministic per-model cost estimator

# Description

Create `packages/db/src/observability/cost.ts` — a pure, dated cost estimator
that turns an Anthropic `usage` object (input / output / cache-creation /
cache-read tokens) into an estimated USD cost from a static per-model price
table. Clearly labelled an estimate (AD-4).

## Acceptance Criteria
- [ ] `estimateCostUsd(model, usage)` returns a number from a static per-model
      rate table (input, output, cache-write, cache-read rates per token).
- [ ] The price table is versioned/dated (a `PRICE_TABLE_DATE` constant) and
      covers the models the coach uses (the `DEFAULT_MODEL` + the Opus/Sonnet/Haiku
      ids); an unknown model falls back to a documented default rate, not a throw.
- [ ] Cache-read tokens are priced lower than input tokens (prompt-caching aware),
      matching the `usage` shape the client returns.
- [ ] Pure and total; exported for direct unit testing. Vitest covers: a known
      model, cache tokens, the unknown-model fallback, and zero usage.

## Technical Details
- New file only: `observability/cost.ts` (+ `cost.test.ts`). No I/O, no network.
- Input type is `Anthropic.Message["usage"]` (what `LlmResponse.usage` carries).
- Keep the table small and readable with a clear "estimate, rates as of <date>"
  comment; the value is stored on `llm_traces.estimatedCostUsd` by task 4.

## Dependencies
