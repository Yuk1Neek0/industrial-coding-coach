# Task: Per-repo Issues list Page Spec + Claude Design prompt

## Description

Author the **Page Spec** and **Claude Design prompt** for the per-repo
Issues list page (FR-11, R5) — the entry point that the user reaches off
their imported-repo page and from which they navigate to a learning unit.
Per R5 there is **no global cross-repo issues index** in M7; this page is
strictly per imported repo. Ships docs only — no code, no `apps/web`
edits — and is the design hand-off gate that, together with task 006,
unblocks the integration work in task 008.

Touches different files than task 006 (this is the fifth UI piece — its
own Page Spec and its own prompt — under `docs/design/`), so it can run in
parallel with task 006 with no file conflicts.

- [ ] Page Spec at `docs/design/per-repo-issues-list.page-spec.md` covering:
      route `apps/web/app/repos/[owner]/[repo]/issues/page.tsx`, reading
      the GitHub-issue list via the **extended M11 GitHub client**
      (task 002, ADR 0009), and per-row navigation to the Issue Learning
      Workspace page at `[owner]/[repo]/issues/[issueRef]`.

header (page title, route, status), product context, data contract,
interaction spec, accessibility, exclusions. The data contract pastes in
the typed issue-list shape from task 002's
`packages/db/src/github/` extension.

under `docs/design/` only; **no overlap** with task 006 (different files
per the epic's Implementation Strategy: tasks 006 and 007 both write Page
Specs under `docs/design/` but each touches different files, so they do
not conflict).
