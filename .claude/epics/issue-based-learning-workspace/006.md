# Task: Issue Learning Workspace + Review Checklist + Understanding Questions + Challenge Panel — Page Specs + Claude Design prompts

## Description

Author the **Page Specs** and **Claude Design prompts** for the four M7 UI
pieces called out in FR-10 — the UI hand-off gate. Per ADR 0007, no UI is
generated before a Page Spec and a prompt exist; Claude Design is the only
UI-generation tool used across M7 (v0 is superseded by ADR 0007). This
task ships docs only — no code, no `apps/web` edits — and is the design
hand-off gate that unblocks task 008's integration work.

Four UIs, one task (mirrors how M6 task 107 and M8 task 115 batched four
Page Specs into a single design-hand-off task):

1. **Issue Learning Workspace page** — top-level page composing the other
   three components.
2. **Review Checklist UI** — checklist progress component (R4 — no
   gating).
3. **Understanding Questions UI** — answer-entry form + Score / Weak Area
   block, **mirroring M8's Score / Weak Area UI** per the PRD.
4. **Challenge Panel** — read-only M9-deferred stub renderer (FR-7, R3).

      read-only stub renderer reading `learning_units.challenge_concept`

## Technical Details

Follow the existing `docs/design/` Page Spec conventions used by M4 / M5 /
M6 / M8 — header (page title, route, status), product context, data
contract (the typed shapes consumed/produced), interaction spec,
accessibility notes, and a "What this page does not do" exclusions
section.

Follow the `docs/design/ui-prompts/` convention used by M6 (task 107) and M8
(task 115): one prompt file per page with the data contract pasted in,
explicit Claude Design instructions, and the components-from-shadcn/ui
notes.

**Claude Design only (ADR 0007).** v0 is superseded; any wording suggesting
v0 in the milestone plan does not apply here. The Page Specs must
explicitly call out Claude Design as the generation tool.

This is the design hand-off gate. No code in this task — it unblocks the
integration in task 008. Touches files under `docs/design/` only;
**no overlap** with task 007's per-repo Issues list Page Spec (different
files).
