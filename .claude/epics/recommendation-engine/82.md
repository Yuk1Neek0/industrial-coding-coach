# Task: Integrate the Recommendation Intake + Result UI

## Description

Integrate the Claude Design-generated Intake and Result page drafts into
`apps/web` — wire them to the scoring module, the recommendation narrative call,
and the data-access layer so a user can submit their context, get a
recommendation, and review/edit it.

## Acceptance Criteria
- [x] The Intake page collects the nine fields and submits them server-side.
- [x] Submission runs deterministic scoring, then the narrative call, then
      persists the recommendation.
- [x] The Result page renders the recommended path/templates, rejected
      alternatives, trade-off explanation, and learning checkpoints.
- [x] The user can review and edit the stored recommendation.
- [x] Errors (missing API key, SDK failure) surface cleanly, not as crashes.
- [x] `pnpm lint`, `pnpm typecheck`, `pnpm build`, `pnpm test` pass with no API
      key set.

## Technical Details

Follows the M2/M11 UI-integration pattern. The narrative call is a server
action; the page never calls the SDK directly. UI drafts come from Claude Design
(ADR 0007); record integration notes under `docs/design/ui-integration-notes/`.

## Dependencies

Tasks 2, 3, 4 (scoring, narrative, data-access) and 5 (page specs / Claude
Design drafts). Final task of the epic.
