# Task: recommendations schema + migration + intake type model

## Description

Add a `recommendations` table to the existing catalog SQLite database via
Drizzle, and define the typed intake model. This is the foundational task — the
scoring module, the narrative call, and the data-access layer all build on it.

## Acceptance Criteria
- [ ] A `recommendations` table is added to `packages/db/src/schema.ts`,
      storing the intake context, the scored result, and the generated
      narrative; list-valued fields as JSON columns (matching `golden_paths` /
      `templates`).
- [ ] A Drizzle migration is generated and the snapshot/journal updated.
- [ ] A typed intake model covers the nine fields: goal, experience level,
      known stack, job target, time budget, complexity tolerance, project type,
      AI-tool preference, learning focus.
- [ ] No new database is created — the table joins the existing catalog store.
- [ ] `pnpm typecheck` and the migration apply cleanly.

## Technical Details

`schema.ts` is shared with the parallel `stack-explainer` epic — this epic adds
only the `recommendations` table; migration numbering is resolved at merge time.

## Dependencies

None within the epic. Builds on the M2/M3 catalog database (ADR 0006).
