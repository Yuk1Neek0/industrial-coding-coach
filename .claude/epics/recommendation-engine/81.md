# Task: Intake + Result page specs + Claude Design prompts (UI hand-off gate)

## Description

Write the Page Specs for the Recommendation Intake UI and the Recommendation
Result UI, plus the Claude Design prompts that generate their drafts. Per ADR
0007, these artifacts must exist before any Claude Design generation. This task
ends in a **hand-off to the user**, who generates the drafts in Claude Design.

## Acceptance Criteria
- [ ] `docs/design/recommendation-intake-page.md` — Page Spec for the intake
      form covering the nine intake fields.
- [ ] `docs/design/recommendation-result-page.md` — Page Spec for the result
      view: recommended path/templates, rejected alternatives, trade-off
      explanation, learning checkpoints.
- [ ] Claude Design prompts written under `docs/design/ui-prompts/` for both
      pages.
- [ ] Specs follow the format of the existing `docs/design/` page specs.
- [ ] Task ends with an explicit hand-off note for the user to run Claude Design.

## Technical Details

Documentation only — no Claude Design generation in this task. Mirrors the
M2/M3/M11 page-spec tasks (per ADR 0007 the UI tool is Claude Design, not v0).

## Dependencies

None — can start immediately, in parallel with all other tasks.
