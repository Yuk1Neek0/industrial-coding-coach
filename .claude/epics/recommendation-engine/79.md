# Task: Recommendation narrative via Anthropic SDK + mocked tests

## Description

Build the bounded Anthropic SDK call that turns a scored recommendation into the
human-facing coaching narrative. This is the "explanation" half of the hybrid
engine, built on the `llm-foundation` client — a bounded prompt → structured
output call, not an autonomous agent (ADR 0005).

## Acceptance Criteria
- [x] A bounded call on the `packages/ai` client takes the scored result, the
      intake, and catalog data and produces a typed, structured narrative.
- [x] The narrative covers all four dimensions: why each choice fits, complexity
      risks, learning checkpoints, and portfolio value.
- [x] The narrative references the intake context and the recommended entries —
      never generic.
- [x] The call is invoked server-side only and uses structured outputs + prompt
      caching.
- [x] Tests use the `llm-foundation` mock harness; they pass with no API key
      and make no live calls.

## Technical Details

Consumes the LLM client wrapper and mock harness from the `llm-foundation`
epic. Scoring decides; this task only explains — it must not override the
ranking.

## Dependencies

Task 1 (intake model). **Cross-epic:** the `llm-foundation` epic must be merged
first. Runs in parallel with tasks 2 and 4.
