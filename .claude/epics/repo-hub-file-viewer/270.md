# Task: Wire M5/M6 file references into the viewer

## Description

Make the coach's file references clickable (US-3): the M5 Stack Explainer's
"Key files to inspect" and the M6 Project Map's file references currently
render as plain monospace text (named in both retrospectives). Link them to
the snapshot file viewer (#268) at the referenced path.

## Acceptance Criteria

- [ ] M5: entries in the "Key files to inspect" section of
      `apps/web/app/stack/[owner]/[repo]/_components/stack-explainer-flow.tsx`
      link to `/repos/[owner]/[repo]/files?path=<path>` (per the #266 URL
      contract), preserving current styling (link wraps or replaces the
      monospace text, hover/focus visible).
- [ ] M6: file references rendered by
      `apps/web/app/map/[owner]/[repo]/_components/map-flow.tsx` (locate all
      render points — flows, debug path, related files) link the same way.
- [ ] AD-5 honored: links are built only from paths the analysis stored for
      this owner/repo snapshot; if a rendered reference is free text not
      guaranteed to be a tree path, link it anyway only if the viewer's
      unknown-path state is a graceful not-found (it is, per #268) — never
      crash, never fabricate paths.
- [ ] Survey both components for ALL file-path render points (M16 lesson:
      enumerate consumers — grep for the monospace/path-rendering idioms in
      each file), and list in the completion report which were linked and
      which intentionally left as text (e.g. globs, directories if the
      viewer only addresses files).
- [ ] `pnpm lint` / `typecheck` / web `build` pass.

## Technical Details

- Touch only the two components (+ their feature stylesheets if a link class
  is genuinely needed). Do not modify the viewer, hub, or import flow.
- Both are existing-page upgrades — no Page Spec needed (M16 #259
  precedent).
