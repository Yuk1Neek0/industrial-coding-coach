# Task: Page Spec — Repos Hub

## Description

Write the Page Spec for the `/repos` hub page (US-1): the list of imported
repository snapshots that replaces M16's redirect-to-import placeholder.
Docs-only task; the implementation task (#267) builds directly from this
spec (AD-2).

## Acceptance Criteria

- [ ] `docs/design/repos-hub-page.page-spec.md` exists, following the
      structure of recent specs (e.g. `observability-page.page-spec.md`,
      `per-repo-issues-list.page-spec.md`): purpose, route, data
      sources, layout sections, states, interactions, a11y notes.
- [ ] Specifies: route `/repos`; data from `listImportedRepos` (owner, repo,
      ref, importedAt, fileCount, keyFileCount); shared `AppNav`
      (`active="repos"`).
- [ ] Specifies each repo row's content and its per-repo area links: Files
      (the new viewer), Issues, Challenges, Stack, Map, Reviews, Portfolio,
      Delivery, Observability — with the exact hrefs.
- [ ] Specifies empty state (no imports yet → CTA to `/import`) and the
      re-import affordance (link to `/import`).
- [ ] States the styling source: the repos feature's existing conventions
      (`repos.css`, IBM Plex via the repos layout) — no new design system.

## Technical Details

- Read `apps/web/app/repos/layout.tsx` + `repos.css` and one or two recent
  page specs for format and tone before writing.
- The hub is a Server Component reading SQLite only; spec the loading/error
  conventions consistent with the repos feature (`loading.tsx`, `error.tsx`).
