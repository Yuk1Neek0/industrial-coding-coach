# Task: Open-source readiness (CONTRIBUTING + make repo public)

## Description

Prepare the project to be a public open-source repository. `LICENSE` (MIT) is
already committed; this task adds the remaining pieces and makes the repo
public.

## Acceptance Criteria
- [ ] `CONTRIBUTING.md` created — workflow (CCPM, PRs, CI), how to run locally,
      how to file issues
- [ ] `README.md` shows the open-source license and contribution pointer
      (coordinate with task 004)
- [ ] Repository made **public** — gated on explicit human go-ahead
- [ ] On going public: ADR 0004 revisited — branch protection + CodeQL become
      available and should be enabled

## Technical Details

`LICENSE` (MIT) is done. Making the repo public is an outward, hard-to-reverse
action: do not execute it without explicit human confirmation. Going public
also unblocks the items deferred in ADR 0004.

## Dependencies
PRD; `LICENSE` (committed). Coordinates with task 004 on `README.md`.
