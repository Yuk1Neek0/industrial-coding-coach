# Task: LangGraph mapping pipeline + mocked tests

## Description

Build the LangGraph workflow that orchestrates the multi-step mapping pipeline
and produces all seven structured outputs: architecture overview, key-file map,
request/data flow, state flow, AI-call flow, Mermaid diagram source, and debug
path. This is the M6 critical path and the LangChain/LangGraph showcase.

## Acceptance Criteria
- [ ] A LangGraph workflow sequences the seven outputs, with deterministic nodes
      where a step is mechanical and agentic LLM+retrieval nodes where reasoning
      over code is needed.
- [ ] Claude is reached via LangChain's Anthropic integration.
- [ ] The pipeline consumes the deterministic ingestion structure (task 003) and
      retrieves code through the RAG layer (task 004).
- [ ] Output is a single typed structure covering all seven outputs, including
      Mermaid diagram source for the flows.
- [ ] Every file/module reference resolves to a real snapshot path; Mermaid
      nodes correspond to real files/modules.
- [ ] A non-AI project yields an explicit "not applicable" AI-call flow rather
      than failing; partial structure degrades gracefully.
- [ ] Tested with mocked/recorded model responses per the `llm-foundation` test
      strategy; CI makes no live API calls.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

LangGraph state graph: ingestion → architecture overview → key-file map →
request/data flow → state flow → AI-call flow → debug path → Mermaid assembly.
RAG retrieval feeds the agentic nodes. The whole pipeline stays inside the M6
package per ADR 0005. Token use stays bounded via retrieval.

## Dependencies

- Task 003 (deterministic ingestion).
- Task 004 (RAG layer).
