# Task: project_maps schema + Drizzle migration

## Description

Add a `project_maps` table to the existing SQLite database (ADR 0006) to store
a generated project logic map, keyed by imported snapshot. Generate the Drizzle
migration. No new database.

## Acceptance Criteria
- [ ] `project_maps` table defined in `packages/db/src/schema.ts`, keyed to a
      `repo_snapshots` row (`owner/repo` + ref), one map per snapshot.
- [ ] Columns cover all seven outputs — architecture overview, key-file map,
      request/data flow, state flow, AI-call flow, Mermaid diagram source,
      debug path — with structured/list-valued fields as JSON columns.
- [ ] Drizzle migration generated and committed under `packages/db/drizzle/`.
- [ ] Insert/select types exported, consistent with existing tables.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

Mirror the `stack_explanations` table pattern: child of `repo_snapshots`,
deleted with its parent, unique per snapshot. Use JSON columns for the
structured map sections. Migration numbering is resolved at epic merge time
(the parallel `diff-review` epic also adds tables).

## Dependencies
- M11 `repo_snapshots` schema (shipped). ADR 0006.
