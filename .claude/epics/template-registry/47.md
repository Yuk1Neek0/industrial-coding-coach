# Task: Template Registry page spec + v0 prompt (v0 hand-off gate)

## Description

Write the Page Spec for the Template Registry UI and the v0 prompt that
generates its draft. Per the project v0 rule, this artifact must exist under
`docs/design/` before any v0 generation. This task ends in a **hand-off to the
user**, who generates the draft in v0.

## Acceptance Criteria
- [ ] A Page Spec for the Template Registry exists under `docs/design/`.
- [ ] The spec covers: a list view (15 templates, browsable by category) and a
      detail view (one template incl. its fit-score presentation).
- [ ] The spec deliberately mirrors the M2 Catalog page structure so registry
      and catalog feel like one product.
- [ ] A v0 prompt derived from the spec is included.
- [ ] The task is handed off to the user for v0 generation.

## Technical Details

- Follow the M2 Catalog page spec as the template for format and depth.
- The fit-score presentation is the one genuinely new UI element — specify it
  explicitly.
- Use `packages/ui` (shadcn/ui) components only.

## Dependencies

- Blocks task 005 (integration needs the v0 output).
