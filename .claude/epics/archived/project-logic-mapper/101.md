# Task: Install LangChain.js + LangGraph; setup note + tool-radar entry

## Description

Install LangChain.js and LangGraph as scoped dependencies for the M6 pipeline,
following their official documentation. Record the install in a setup note and
update the tool radar. Per ADR 0005, LangChain/LangGraph are confined to the M6
pipeline; this task establishes the dependency surface the rest of the epic
builds on.

## Acceptance Criteria
- [ ] LangChain.js and LangGraph (`@langchain/*`, `@langchain/langgraph`,
      `@langchain/anthropic`) installed per official docs, in the package that
      will host the M6 pipeline.
- [ ] Versions and the official-docs source recorded in a setup note under
      `docs/setup/`.
- [ ] Tool radar updated: LangChain.js / LangGraph entered as Trial, scoped to
      M6 (per ADR 0005 consequences).
- [ ] `pnpm install`, `pnpm typecheck`, `pnpm build` pass with the new deps.

## Technical Details

Follow the official LangChain.js and LangGraph installation docs — do not
install from memory (CLAUDE.md hard rule). Scope the dependency to the M6
pipeline package rather than the workspace root. Claude is reached via
`@langchain/anthropic`; reuse the `llm-foundation` API-key configuration
convention where practical.

## Dependencies
- ADR 0005 (mechanism), ADR 0001 (tool adoption).
- `llm-foundation` API-key config convention (shipped).
