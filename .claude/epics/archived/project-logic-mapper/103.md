# Task: Deterministic ingestion module + tests

## Description

Build the deterministic ingestion module that turns an imported snapshot into a
structured base for the pipeline: the file tree, the module/dependency graph,
and import relationships. This is a pure, fully tested module — the
reproducible structural foundation the LangGraph pipeline reasons over.

## Acceptance Criteria
- [ ] Module reads a snapshot via the M11 data-access layer and produces a typed
      structure: file tree, module/dependency graph, and import relationships.
- [ ] Reuses M5 stack-detection output (`packages/db/src/stack`) for frameworks
      and entry points — no re-detection.
- [ ] Pure and deterministic — no LLM calls, no network.
- [ ] Unit tests cover representative snapshots, including a snapshot with no
      clear entry point.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

Parse import/require statements from key files to build the dependency graph.
Degrade gracefully on partially recognized structure. Output is the ingestion
input for both the RAG layer (task 004) and the LangGraph pipeline (task 005).

## Dependencies
- M11 snapshot data-access layer (shipped).
- M5 stack-detection module (shipped).
