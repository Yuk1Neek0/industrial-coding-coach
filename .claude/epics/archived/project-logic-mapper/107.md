# Task: Project Logic Mapper page specs + Claude Design prompts

## Description

Author the Page Specs and Claude Design prompts for the four M6 UI pieces —
the UI hand-off gate. Per ADR 0007, no UI is generated before a page spec and a
prompt exist.

## Acceptance Criteria
- [ ] Page Specs under `docs/design/` for: Project Map page, Architecture Flow
      Viewer, File Map Explorer, Debug Path UI.
- [ ] A Claude Design prompt under `docs/design/ui-prompts/` for each.
- [ ] Specs cover how the seven pipeline outputs map onto the four pages,
      including client-side Mermaid diagram rendering.
- [ ] Specs reference the typed pipeline output shape so integration is
      unambiguous.

## Technical Details

by M4/M5. No code in this task — it is the design hand-off gate that unblocks
task 008.
