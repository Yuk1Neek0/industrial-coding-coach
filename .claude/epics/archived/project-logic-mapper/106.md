# Task: project-maps data-access layer + file-reference integrity check

## Description

Build the typed data-access layer for project maps — create, read, and update —
plus a file-reference integrity check that verifies every path cited by a
generated map resolves to a real file in the snapshot.

## Acceptance Criteria
- [ ] Typed module to create, read, and update `project_maps` rows server-side.
- [ ] A file-reference integrity check validates every cited path against the
      snapshot's file set.
- [ ] Tests cover create/read/update and the integrity check, including a map
      with an unresolvable reference.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

Mirror the `stack_explanations` data-access pattern. The integrity check is
reused at integration time to guard project-tied output (PRD FR-6).

- M11 snapshot data-access layer (shipped).
