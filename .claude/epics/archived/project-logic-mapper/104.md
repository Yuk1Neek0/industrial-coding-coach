# Task: LangChain RAG layer

## Description

Build the LangChain retrieval layer: load, split, and index the snapshot's
files so the LangGraph pipeline can retrieve the code relevant to each step on
demand, instead of stuffing the whole repository into model context.

## Acceptance Criteria
- [ ] Snapshot files loaded and split using LangChain document loaders and
      splitters.
- [ ] An in-memory retriever indexes the split documents and returns relevant
      files/chunks for a query.
- [ ] Retrieval is exercised by tests with a sample snapshot (no live API
      calls).
- [ ] Token use stays bounded for large repositories.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

Use LangChain.js document loaders, text splitters, and a retriever (in-memory
vector or keyword retriever is sufficient for the MVP). The retriever consumes
the deterministic ingestion output for file selection. Stays inside the M6
pipeline package per ADR 0005.

## Dependencies
- Task 001 (LangChain.js installed).
- Task 003 ingestion output (consumed at pipeline wiring time).
