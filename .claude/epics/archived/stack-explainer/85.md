# Task: Stack detection module + tests

## Description

Build the deterministic module that parses an imported-repo snapshot's package
and config files and identifies the major tools and frameworks. This gives the
explanation call a known, reproducible tool set to reason over.

## Acceptance Criteria
- [ ] A pure module reads a snapshot via the M11 data-access layer and returns
      the set of major tools/frameworks detected from package/config files.
- [ ] Detection is deterministic and reproducible.
- [ ] A snapshot whose stack is only partially recognized degrades gracefully.
- [ ] Unit tests cover detection across representative package/config inputs.

## Technical Details

Reuses the M11 snapshot data-access layer — no second snapshot-access path.
Detection is separate from the LLM call so it stays testable.

## Dependencies

None — can start immediately. Runs in parallel with tasks 1 and 5.

- Size: M
- Hours: 7
