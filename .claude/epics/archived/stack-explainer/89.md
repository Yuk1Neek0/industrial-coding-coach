# Task: Integrate the Stack Explainer UI

## Description

Integrate the Claude Design-generated Stack Explainer page drafts into
`apps/web` — wire the Stack Explanation page, Stack Decision Map, and
Alternatives Comparison UIs to the explanation call and the data-access layer.

## Acceptance Criteria
- [ ] A user selects an imported repo and triggers a stack explanation.
- [ ] Triggering runs the explanation call server-side and persists the result.
- [ ] The Stack Explanation page renders the decision map, per-tool purpose,
      key files to inspect, and debugging entry points.
- [ ] The Decision Map and Alternatives Comparison UIs render their data.
- [ ] Errors (missing API key, SDK failure, unrecognized stack) surface
      cleanly, not as crashes.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm build`, `pnpm test` pass with no API
      key set.

## Technical Details

Follows the M11 UI-integration pattern. The explanation call is a server action;
the page never calls the SDK directly. UI drafts come from Claude Design (ADR
0007); record integration notes under `docs/design/ui-integration-notes/`.

## Dependencies

Tasks 3, 4 (explanation call, data-access) and 5 (page specs / Claude Design
drafts). Final task of the epic.
