# Task: Stack Explainer page specs + Claude Design prompts (UI hand-off gate)

## Description

Write the Page Specs for the three Stack Explainer UIs and the Claude Design
prompts that generate their drafts. Per ADR 0007, these artifacts must exist
before any Claude Design generation. This task ends in a **hand-off to the
user**, who generates the drafts in Claude Design.

## Acceptance Criteria
- [ ] `docs/design/stack-explanation-page.md` — Page Spec for the full
      per-project stack explanation view.
- [ ] `docs/design/stack-decision-map.md` — Page Spec for the tool-by-tool
      decision map UI.
- [ ] `docs/design/alternatives-comparison.md` — Page Spec for the alternatives
      and trade-offs comparison UI.
- [ ] Claude Design prompts written under `docs/design/ui-prompts/` for all
      three.
- [ ] Specs follow the format of the existing `docs/design/` page specs.
- [ ] Task ends with an explicit hand-off note for the user to run Claude Design.

## Technical Details

Documentation only — no Claude Design generation in this task. Mirrors the
M2/M3/M11 page-spec tasks (per ADR 0007 the UI tool is Claude Design, not v0).

## Dependencies

None — can start immediately, in parallel with all other tasks.
