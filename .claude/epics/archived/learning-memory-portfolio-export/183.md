# Task: PDF exporter — install renderer + render bundle

## Description

Install the chosen PDF rendering library per the official-installation
rule (CLAUDE.md) and ship the `renderPortfolioPdf` function that turns
a `learning_memories` row into a single `portfolio.pdf` (FR-7) suitable
for résumé attachment. Library choice is locked in this task and
recorded in a setup note (or a small ADR if it touches the trial-track
decision tree).

## Acceptance Criteria

- [ ] **Library decision recorded** at
      `docs/decisions/<NNNN>-pdf-rendering.md` (or a setup note under
      `docs/current/`) — covers the choice (default lean:
      `@react-pdf/renderer` for the local-first / no-extra-binary
      footprint), the alternative considered (e.g. `puppeteer`), and
      the reason. Cross-references the official installation
      documentation used.
- [ ] Dependency added to `packages/db/package.json` per the chosen
      library's official README. Lockfile refreshed via
      `pnpm install` (full workspace, not `--filter`).
- [ ] `packages/db/src/learning-memories/export-pdf.ts` exports
      `renderPortfolioPdf(memory: LearningMemory): Promise<Buffer>` —
      one-function surface so the library is swappable.
- [ ] PDF content order matches the markdown bundle's `portfolio.md`
      (architecture → memory tree → Q&A → bullets → debug stories) so
      the PDF and the markdown bundle are visibly the same content in
      different containers.
- [ ] PDF filename helper: `portfolio-<owner>-<repo>-<snapshot.id>.pdf`
      (same slug rule as task 7).
- [ ] Tests:
      - Smoke test: renderer returns a non-empty buffer on the seeded
        happy-path fixture.
      - Structural test: PDF contains identifiable strings from each
        of the five sections (text-extract round-trip with a small
        helper; not a pixel comparison).
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm build`, `pnpm test` pass.
      `pnpm build` must succeed on a fresh `pnpm install` (no missing
      binary deps).

## Technical Details

- **Library decision discipline** — the M9 retrospective's "official
  installation rule" applies. Install only via the library's official
  installation method (`pnpm add @react-pdf/renderer` from its README,
  or the equivalent for an alternative); record the source.
- Keep `renderPortfolioPdf` thin — one function in, buffer out. All
  rendering primitives (which font, which margins) live behind it so
  the library is swappable behind a single edge.
- Run the renderer server-side only (Server Action). Don't bundle PDF
  primitives into the browser bundle.

## Dependencies

In-epic: task 007 (markdown bundle is the content source — the PDF is
*the same content* in PDF form).
Out-of-epic: a new library install.
