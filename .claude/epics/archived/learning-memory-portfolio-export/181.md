# Task: Résumé-bullet bounded SDK call

## Description

The second of M10's two narrative-generation calls: a bounded Anthropic
SDK call on the shipped `llm-foundation` client that produces a typed
`ResumeBullet[]` where each bullet is in industry-standard
"verb + outcome + technology" form (US-2). Tool use reads M5
`stack_explanations` + M6 `project_maps` + M7 `learning_units` +
M9 `challenge_attempts`. A forced final `submit_resume_bullets` tool
yields the structured output. The output is integrity-checked (task
002) before persistence.

Sequenced after task 005 to match the M7/M9 generation/grading
two-call cadence and to avoid the barrel-export conflict with
`packages/db/src/learning-memories/`.

## Acceptance Criteria

- [ ] `packages/db/src/learning-memories/generate-bullets.ts` exports
      `generateResumeBullets(snapshotId): Promise<ResumeBullet[]>`.
- [ ] Bounded SDK call on `@workspace/ai`:
      - Fixed tool set: `read_stack_explanation`, `read_project_map_entry`,
        `read_learning_unit`, `read_challenge_attempt`,
        `submit_resume_bullets` (forced final).
      - Short turn cap (≤ 5) with `submit_resume_bullets` forced on the
        last turn.
      - System prompt enforces: ≤ 160 chars per bullet, "verb + outcome
        + technology" shape, no claims that cannot be grounded in a
        real M5 / M6 / M7 / M9 row.
- [ ] Output passes the integrity check from task 002 — every named
      technology resolves to a real M5 row and every named file /
      module to a real M6 row. Failing outputs are rejected.
- [ ] Bullet length enforced in code (post-SDK) — any bullet > 160
      chars is rejected before persistence (US-2).
- [ ] Tests run on the `@workspace/ai` mock transport:
      - Happy path: ≥ 4 well-formed bullets on a seeded fixture.
      - Hallucinated-technology fixture rejected with `missing` list.
      - Over-length fixture rejected with a length-violation message.
      - "Verb + outcome + technology" prefix check covered by a regex
        / shape assertion on each bullet.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test` pass with **no**
      `ANTHROPIC_API_KEY` set.

## Technical Details

- Build on top of task 005's scaffolding (shared tool definitions,
  shared prompt helpers). Don't duplicate — extract any
  cross-call helper into a small shared file inside the module.
- Use the existing `@workspace/ai` mock transport pattern from M7 / M8
  / M9 — no live API calls in CI.
- `ResumeBullet` TS type declared in task 001's `schema.ts` exports.

## Dependencies

In-epic: tasks 001 (types), 002 (integrity check), 005 (scaffolding +
serialization).
Out-of-epic: `llm-foundation` (shipped); M5/M6/M7/M9 DALs (shipped).
