# Task: Link catalog template chips to template detail pages

## Description

The M2 catalog detail page renders each Golden Path's `templatesReferenced`
as plain-text chips (the section hint literally says "M2 · plain text").
Every value is a template slug guaranteed by the referential-integrity test
to resolve to a registry entry. Make each chip a link to
`/templates/[slug]`. This is the follow-up named in the M3 retrospective.

## Acceptance Criteria

- [ ] In `apps/web/app/catalog/_components/detail-view.tsx`, each
      `templatesReferenced` chip renders as a `next/link` to
      `/templates/<slug>` while keeping the chip styling.
- [ ] The "M2 · plain text" section hint is updated (e.g. "from the Template
      Registry").
- [ ] Links work for both curated and Backstage-imported templates (slug
      resolution is already guaranteed; no extra validation layer added).
- [ ] Chip hover/focus states remain usable (link inherits or extends `.chip`
      styling; keyboard focus visible).
- [ ] `pnpm lint`, `pnpm typecheck`, web `build` pass.

## Technical Details

- Current rendering: `detail-view.tsx` lines ~129–135 (`<span className="chip">`).
- Use `next/link`; the template route is `apps/web/app/templates/[slug]`.
- Do not add a resolver call — the slugs are the registry slugs.
