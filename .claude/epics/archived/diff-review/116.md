# Task: Integrate the Diff Review UI

## Description

Integrate the four Diff Review UI pieces into `apps/web` and wire them to the
review call, the grading call, and the diff-reviews data-access layer —
including the full answer-and-score loop.

## Acceptance Criteria
- [ ] Diff Review page, Risk Analysis Panel, Understanding Check UI, and Score /
      Weak Area UI integrated into `apps/web` and routed.
- [ ] A user selects a PR on an imported repo, gets the review, answers the
      comprehension questions, and receives a graded score and weak-area
      breakdown.
- [ ] Reviews, answers, and scores persist via the data-access layer and read
      back.
- [ ] File references shown in the UI pass the integrity check.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm build`, `pnpm test` pass with no API
      key set.

## Technical Details

Build from the task 006 page specs / Claude Design drafts. Routing additions to
`apps/web` are additive; coordinate at merge time with the parallel
`project-logic-mapper` epic.

- Task 005 (data-access layer).
- Task 006 (page specs + prompts).
