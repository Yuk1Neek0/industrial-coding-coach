# Task: Understanding-check grading call + mocked tests

## Description

Build the bounded Anthropic SDK call that grades the user's answers to the
comprehension questions, producing a numeric score and a weak-area breakdown.

## Acceptance Criteria
- [ ] A bounded Anthropic SDK call on the `llm-foundation` client takes the
      comprehension questions and the user's answers and produces a typed score
      and weak-area breakdown.
- [ ] Grading output is structured and reproducible under the test strategy.
- [ ] Tested with mocked/recorded SDK responses; CI makes no live API calls.
- [ ] Graceful handling of partial or empty answers.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

Consumes the comprehension-questions shape from task 003. A separate bounded
call from the review call, so grading is reproducible and the question set is
fixed before any answer is graded.

## Dependencies
- Task 003 (comprehension-questions shape).
- `llm-foundation` client (shipped).
