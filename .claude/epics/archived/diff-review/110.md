# Task: diff_reviews schema + Drizzle migration

## Description

Add a `diff_reviews` table to the existing SQLite database (ADR 0006) to store
a generated diff review, the user's answers, and the grading score — keyed by
repo and PR number. Generate the Drizzle migration. No new database.

## Acceptance Criteria
- [ ] `diff_reviews` table defined in `packages/db/src/schema.ts`, keyed by repo
      identity and PR number.
- [ ] Columns cover the six review outputs (changed-file explanation,
      core-logic explanation, risk analysis, test suggestions, comprehension
      questions) plus the user's answers and the score / weak-area breakdown —
      structured/list-valued fields as JSON columns.
- [ ] Drizzle migration generated and committed under `packages/db/drizzle/`.
- [ ] Insert/select types exported, consistent with existing tables.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

Follow the existing table conventions (e.g. `stack_explanations`). Answers and
score may be nullable until the user completes the understanding check.
Migration numbering is resolved at epic merge time (the parallel
`project-logic-mapper` epic also adds a table).

## Dependencies
- ADR 0006. Existing schema conventions.
