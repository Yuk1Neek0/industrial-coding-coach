# Task: Diff review call via Anthropic SDK + mocked tests

## Description

Build the bounded Anthropic SDK call (per ADR 0005) that reviews a PR's change
model and produces the structured review: a changed-file explanation, a
core-logic explanation, a risk analysis, test suggestions, and comprehension
questions.

## Acceptance Criteria
- [ ] A bounded Anthropic SDK call on the `llm-foundation` client produces typed
      structured output: changed-file explanation, core-logic explanation, risk
      analysis, test suggestions, comprehension questions.
- [ ] Uses tool use to read specific PR files; a bounded call, not an
      autonomous agent.
- [ ] Every explanation and risk references the actual diff; file references
      resolve to real PR paths; each risk is tied to a changed file/hunk.
- [ ] Tested with mocked/recorded SDK responses per the `llm-foundation` test
      strategy; CI makes no live API calls.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

Consumes the change model from task 002. Mirror the M5 explanation-call pattern
(bounded prompt → structured output, tool use for file reads). The comprehension
questions' typed shape is the input contract for the grading call (task 004).

## Dependencies
- Task 002 (change model).
- `llm-foundation` client (shipped).
