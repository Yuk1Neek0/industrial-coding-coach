# Task: Typed template data-access layer + tests

## Description

Build the typed data-access module for the template registry, usable
server-side by the Next.js app. Includes the resolver that turns a Golden Path's
`templatesReferenced` slugs into full template entries (PRD FR-5).

## Acceptance Criteria
- [ ] A typed module exposes: list all templates, get by slug, list by category.
- [ ] A `resolveTemplates(slugs)` function returns full template entries for a
      slug array (used by the catalog to expand `templatesReferenced`).
- [ ] All functions are fully typed; no `any`.
- [ ] Unit tests cover list, get-by-slug (hit + miss), list-by-category, and
      `resolveTemplates`.
- [ ] `pnpm --filter @workspace/db test` passes.
