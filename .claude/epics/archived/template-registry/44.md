# Task: Template schema + migration

## Description

Add a `templates` table to the existing catalog SQLite database (ADR 0006) via
Drizzle. This is the foundational task — the data-access layer, seed, and UI all
build on this schema. No new database is created; the table joins `golden_paths`
in the existing store.

## Acceptance Criteria
- [ ] A `templates` Drizzle table is defined in `packages/db/src/schema.ts`.
- [ ] Fields per PRD FR-1: `id`, `slug`, `name`, `category`, `summary`,
      `what_it_generates`, `why_used`, `fit_criteria`, `fit_factors`, `risks`,
      `alternatives`, `learning_notes`, `sources`, `created_at`, `updated_at`.
- [ ] List-valued fields (`risks`, `alternatives`, `sources`, `fit_factors`)
      stored as JSON columns — same pattern as `golden_paths`.
- [ ] `Template` / `NewTemplate` types are exported.
- [ ] A Drizzle migration is generated and applies cleanly to a fresh DB.

## Technical Details

- Mirror the `golden_paths` table style in `packages/db/src/schema.ts`.
- Generate the migration with `pnpm --filter @workspace/db db:generate`.
- `slug` must be unique — it is the key the M2 catalog references.
- If the schema proves non-trivial, record a short ADR (epic note: "ADR if
  needed").

## Dependencies

- M2 catalog DB + Drizzle setup (complete).
