# Task: Deterministic scoring module + tests

## Description

Build the pure, deterministic scoring function that ranks Golden Paths and
templates against an intake context and decides the recommendation. This is the
"decision" half of the hybrid engine — no LLM involved.

## Acceptance Criteria
- [x] A pure function scores each `golden_paths` and `templates` entry against
      an intake, using the M3 registry's structured fit-data and Golden Path
      metadata.
- [x] Output is a ranked recommendation plus a list of rejected alternatives,
      each with a reason.
- [x] Identical input produces an identical ranking (deterministic).
- [x] Every cited entry resolves to a real catalog slug.
- [x] Unit tests cover scoring, ranking, and rejected-alternative selection.

## Technical Details

Lives in `packages/db` alongside the catalog/template data-access; reuses the
M2/M3 data-access layers — no second catalog-access path.

## Dependencies

Task 1 (intake model + schema). Runs in parallel with tasks 3 and 4.
