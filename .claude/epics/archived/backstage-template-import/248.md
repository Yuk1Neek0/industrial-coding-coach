# Task: Import + seed integration

## Description

Wire the importer into the existing idempotent seed: load all bundled fixtures,
map them to registry rows, and insert them alongside the curated `templateSeed` —
preserving the seed's drop-and-reload idempotency and the registry's
referential-integrity guarantees.

## Acceptance Criteria
- [ ] A helper loads all Backstage fixtures → enrichment pairs →
      `mapBackstageTemplate` → `NewTemplate[]`.
- [ ] `seed.ts` inserts curated `templateSeed` ++ imported rows; re-running the
      seed is idempotent (stable total template count on a second run).
- [ ] No imported slug collides with a curated slug; a test asserts global slug
      uniqueness across curated + imported.
- [ ] The existing `referential-integrity.test.ts` still passes (imported rows
      add slugs; they do not break Golden Path `templatesReferenced`).
- [ ] The data-access functions (`listTemplates`, `getTemplateBySlug`,
      `listTemplatesByCategory`, `resolveTemplates`) return imported rows
      unchanged, including provenance.
- [ ] A test asserts ≥3 imported rows exist with `source = 'backstage'` and every
      NOT-NULL field populated.

## Technical Details
- Extend `packages/db/src/seed.ts` (after the `templateSeed` insert) and add the
  loader helper (in `backstage-import.ts` or a small `backstage-fixtures.ts`).
- Keep the single reproducible seed entry point (`db:seed`).
