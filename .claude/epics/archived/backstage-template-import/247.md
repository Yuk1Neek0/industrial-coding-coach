# Task: Bundled Backstage fixtures + reviewed enrichment

## Description

Commit a version-controlled set of real Backstage software templates and their
reviewed enrichment companions, so the registry can be seeded reproducibly from
in-repo fixtures (no network). This is the content-authoring task that proves the
importer against real definitions.

## Acceptance Criteria
- [ ] At least **3 real** Backstage software templates (`template.yaml`,
      `kind: Template`) are committed as in-repo fixtures, each citing its real
      upstream source (URL/repo + retrieval note).
- [ ] Each fixture has a reviewed enrichment companion supplying every coaching
      field, fully populated (no placeholders, no naked LLM output).
- [ ] Fixtures parse via `parseBackstageTemplate` and pair via the enrichment
      loader without error.
- [ ] Fixtures cover a small spread of categories (e.g. a service scaffold, a
      frontend scaffold, a docs/other template) so the category mapping is
      exercised.
- [ ] Each fixture, run through `mapBackstageTemplate`, yields a complete
      `NewTemplate` (verified by test in #246/#248).

## Technical Details
- Fixtures under a dedicated dir (e.g. `packages/db/src/fixtures/backstage/`):
  `<name>.template.yaml` + matching enrichment companion per #245's convention.
- Use genuine upstream Backstage templates (e.g. from the official
  `backstage/software-templates` repo or well-known examples); record provenance.
- Enrichment content is hand-authored and reviewed like the M3 seed.

## Dependencies
- #244 (parser) and #245 (enrichment format) define the file shapes.
