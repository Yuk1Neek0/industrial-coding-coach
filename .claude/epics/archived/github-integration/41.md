# Task: Import page spec + v0 prompt (v0 hand-off gate)

## Description

Write the Page Spec for the GitHub repo Import UI and the v0 prompt that
generates its draft. Per the project v0 rule, this artifact must exist under
`docs/design/` before any v0 generation. This task ends in a **hand-off to the
user**, who generates the draft in v0.

## Acceptance Criteria
- [ ] A Page Spec for the Import page exists under `docs/design/`.
- [ ] The spec covers: a repo-URL input (+ optional ref), an import trigger, an
      import status/progress state, a success result view, and clear error
      states (invalid URL, not found, rate-limited, auth failure).
- [ ] A v0 prompt derived from the spec is included.
- [ ] The task is handed off to the user for v0 generation.

## Technical Details

- Follow the M2 Catalog page spec as the template for format and depth.
- Error and loading states are first-class — specify them, do not leave them
  implicit.
- Use `packages/ui` (shadcn/ui) components only.

## Dependencies

- Can be written from the PRD at any time — no code dependency.
- Blocks task 006 (integration needs the v0 output).
