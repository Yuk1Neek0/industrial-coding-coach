# Task: Typed data-access layer + tests

## Description

Build the typed data-access layer over imported repo snapshots, usable
server-side by the Next.js app. This is the interface M5 (Stack Explainer) will
read through.

## Acceptance Criteria
- [ ] A typed module exposes: import a repo, list imported repos, get a repo's
      file tree, get a file's content.
- [ ] All functions are fully typed; no `any`.
- [ ] Unit tests cover each function, including miss/empty cases.
- [ ] `pnpm --filter @workspace/db test` (or the chosen package) passes.

## Technical Details

- Mirror the M2/M3 catalog data-access module style.
- Wraps the task-003 import module and the task-001 snapshot storage.
- The `import a repo` function is the entry point the UI calls.

## Dependencies

- Task 001 (storage schema), Task 003 (import module).
