# Task: Integrate the Import UI page

## Description

Integrate the v0-generated Import page draft into `apps/web` — wire it to the
data-access layer so a user can enter a repo URL, trigger an import, and see the
result or a clear error.

## Acceptance Criteria
- [ ] An Import route exists in `apps/web`.
- [ ] Entering a repo URL and triggering import calls the task-004 data-access
      layer and imports the repo.
- [ ] Import status, the success result, and each error state render correctly.
- [ ] A private repo import works when a token is configured.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm build` pass; CI green; no token
      committed.

## Technical Details

- Integrate the v0 output the user generated from task 005.
- Use `dynamic = "force-dynamic"` for routes that read the snapshot DB, matching
  the catalog pages.
- Surface boundary errors from the data-access layer in the UI.

## Dependencies

- Task 004 (data-access layer).
- Task 005 + the user-generated **v0 output** from it.
