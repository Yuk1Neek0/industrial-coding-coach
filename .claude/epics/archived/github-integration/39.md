# Task: Repo import module + key-file selection

## Description

Build the import module that, given `owner/repo` (+ optional ref), uses the
GitHub API client to fetch the file tree and the contents of key files, then
writes a local snapshot. Defines which files count as "key" — the stack and
structure signal M5/M6 need.

## Acceptance Criteria
- [ ] Given a repo, the module fetches the file tree and key-file contents and
      writes a snapshot to local storage (task-001 schema).
- [ ] Key files include: `package.json`, lockfiles, framework/build config
      (`next.config.*`, `tsconfig.json`, etc.), README, and CI workflow files.
- [ ] File-content fetching is selective — respects size and rate limits.
- [ ] Re-importing an existing repo updates its snapshot.
- [ ] Tests cover a representative import (GitHub calls mocked).

## Technical Details

- Sits on the task-002 client and the task-001 storage schema.
- Snapshot keyed by `owner/repo` + ref.
- Read-only — never writes to the user's GitHub repo.

## Dependencies

- Task 001 (storage schema), Task 002 (API client). Chains after both.
