# Task: GitHub API client + token auth + rate-limit/error handling

## Description

Build the GitHub API client: authenticate with a token, fetch a repository's
file tree, fetch individual file contents, fetch repo metadata, and handle rate
limits and boundary errors. This is the network layer the import module sits on.

## Acceptance Criteria
- [ ] The client reads a GitHub token from the environment (`.env`); no token
      is committed.
- [ ] It can fetch: repo metadata, the file tree for a ref, and a file's
      contents.
- [ ] Rate-limit responses are detected and surfaced (not silently swallowed).
- [ ] Boundary errors — invalid URL, repo not found, auth failure — return
      clear, typed error results.
- [ ] Unit tests cover success and each error path (network calls mocked).

## Technical Details

- Use the GitHub REST API or the `gh` CLI — decision recorded in the task-001
  ADR.
- New module/package; fully typed; read-only scope.
- Selective file fetching — do not clone the whole repo.

## Dependencies

- Runs in parallel with task 005 (page spec).
