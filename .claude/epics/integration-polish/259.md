# Task: Reviews PR picker — selectable list with number-entry fallback

## Description

Upgrade the M8 reviews PR picker
(`apps/web/app/reviews/[owner]/[repo]/_components/pr-picker.tsx`) from a
number-entry form to a selectable list of the repo's pull requests, backed by
the new `listPullRequests` client method (#258). Keep number entry as the
fallback when the list can't load (offline / rate-limited), preserving the
current path exactly.

## Acceptance Criteria

- [ ] A server action (in the existing `actions.ts`) lists PRs via
      `listPullRequests` and returns either the list or the typed error.
- [ ] The picker renders a selectable list showing PR number, title, and
      state; selecting one starts the review with that number through the
      existing start-review path (no change to the review pipeline).
- [ ] On typed error (offline, rate-limited, not found) the picker degrades
      to the current number-entry form with a short notice — the existing
      flow remains fully usable.
- [ ] Empty state (repo has no open PRs) is handled with a clear message and
      the number-entry fallback available.
- [ ] `truncated: true` is surfaced (e.g. "showing first N PRs").
- [ ] `pnpm lint`, `pnpm typecheck`, web `build` pass.

## Technical Details

- Wire through the same client construction the existing review actions use
  (`apps/web/app/reviews/[owner]/[repo]/actions.ts`).
- This is an upgrade of an existing M8 page, not a new page — per the v0
  rule, no new Page Spec is required; follow the page's existing component
  conventions and styling.
- Do not remove or weaken the number-entry path: it is the offline story.
