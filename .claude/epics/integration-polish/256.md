# Task: Shared AppNav component + adoption across feature chromes

## Description

Replace the 12 per-feature `AppNav` copies (each living in a feature
`chrome.tsx`) with one shared component, and kill every dead link. Today the
copies disagree about which routes exist; the catalog copy ships
`<a href="#">Templates</a>`, `<a href="#">Sessions</a>`, `<a href="#">Docs</a>`
and a fake ⌘K search affordance. This is the follow-up named in the M4, M6,
M7, M8, M12, and M13 retrospectives.

## Acceptance Criteria

- [ ] New `apps/web/app/_components/app-nav.tsx` exports a single `AppNav`
      with brand, links to real top-level routes only (Home `/`, Catalog
      `/catalog`, Templates `/templates`, Recommend `/recommend`, Stack
      `/stack`, Map `/map`, Repos `/repos`, Reviews `/reviews`, Import
      `/import`), and an `active` prop highlighting the current area.
- [ ] All 12 feature `chrome.tsx` files render the shared `AppNav` and no
      longer define their own copy; their other exports (e.g. `Badge`) are
      untouched.
- [ ] Repo-scoped areas (issues, challenges, portfolio, delivery,
      observability) are reachable via Repos — no broken absolute links in
      the nav.
- [ ] Zero `href="#"` anchors remain under `apps/web`.
- [ ] The fake ⌘K search affordance is removed.
- [ ] `pnpm lint` and `pnpm typecheck` pass; `pnpm build` (web) passes.

## Technical Details

- Reuse the existing `.nav`, `.nav-brand`, `.nav-links`, `.active` CSS
  conventions — this is consolidation, not a restyle. If a feature's local
  stylesheet lacks `.nav` styles, verify the shared classes resolve (they are
  global today; confirm with one non-catalog page).
- `active` should be a union of area keys, e.g.
  `"home" | "catalog" | "templates" | "recommend" | "stack" | "map" | "repos" | "reviews" | "import"`.
  Repo-scoped chromes (issues/challenges/portfolio/delivery/observability)
  pass `active="repos"`.
- Affected chromes: `catalog`, `templates`, `recommend`, `stack`, `map`,
  `repos`, `repos/[owner]/[repo]/challenges`, `reviews`, `import`,
  `portfolio/[owner]/[repo]`, `delivery/[owner]/[repo]`,
  `observability/[owner]/[repo]` `_components/chrome.tsx`.
- The brand version label (`v0.2 · m2` etc.) differs per copy — pick one
  neutral brand (e.g. `Coach`) without per-milestone labels.
