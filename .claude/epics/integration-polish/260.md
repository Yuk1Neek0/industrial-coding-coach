# Task: Drop M7 stub columns from learning_units (migration 0013)

## Description

`learning_units.challenge_concept` and `learning_units.challenge_type` were
M7 scaffolding for the then-unbuilt challenge system. M9 shipped its own
`challenges` table; its retrospective says to drop the stubs in a cleanup
pass. Remove the columns via a new Drizzle migration and prune every code
path and test that references them, so the schema and the M7 generation
contract describe only what the product uses. Safe because M13 confirmed
`generateLearningUnit`/`gradeLearningUnit` have no production callers yet.
