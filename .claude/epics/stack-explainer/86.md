# Task: Stack explanation via Anthropic SDK + mocked tests

## Description

Build the bounded Anthropic SDK call that produces the stack explanation.
Running on the `llm-foundation` client, it turns the detected tool set into the
structured, project-tied explanation, using tool use to read specific snapshot
files. It is a bounded prompt → structured-output call, not an autonomous agent
(ADR 0005).

## Acceptance Criteria
- [ ] A bounded call on the `packages/ai` client, with tool use to read snapshot
      files, produces a typed, structured explanation: stack decision map,
      per-tool purpose, alternatives + trade-offs, job-market relevance, key
      files to inspect, debugging entry points.
- [ ] Every explanation references actual snapshot files/dependencies — no
      generic tutorial text.
- [ ] Where a detected tool appears in the M3 template registry, the call may
      draw on its authored fit-data for grounding.
- [ ] The call is invoked server-side only and uses structured outputs.
- [ ] Tests use the `llm-foundation` mock harness; they pass with no API key
      and make no live calls.

## Technical Details

Consumes the LLM client wrapper and mock harness from the `llm-foundation`
epic, and the detected tool set from task 2.

## Dependencies

Task 2 (stack detection). **Cross-epic:** the `llm-foundation` epic must be
merged first. Runs in parallel with tasks 1, 4, and 5.
