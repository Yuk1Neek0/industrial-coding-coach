# Task: Stack-explanations data-access layer + file-reference integrity check

## Description

Build the typed data-access layer over the `stack_explanations` table, usable
server-side by the Next.js app, and add the integrity check that proves every
cited file path exists in the snapshot.

## Acceptance Criteria
- [ ] A typed module exposes create, read, and update for stack explanations.
- [ ] A file-reference integrity check proves every file path cited in a stored
      explanation resolves to a real path in the snapshot.
- [ ] The layer is server-side usable from `apps/web`.
- [ ] Unit tests cover create/read/update and the integrity check.

## Technical Details

Lives in `packages/db`. Follows the M11/M3 data-access patterns. The integrity
check enforces the "tied to the project" PRD requirement.
