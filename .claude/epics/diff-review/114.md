# Task: diff-reviews data-access layer + file-reference integrity check

## Description

Build the typed data-access layer for diff reviews — create, read, and update
reviews, and store the user's answers and grading score — plus a file-reference
integrity check that verifies every path cited by a review resolves to a file
in the PR's changed-file set.

## Acceptance Criteria
- [ ] Typed module to create, read, and update `diff_reviews` rows server-side,
      including storing the user's answers and the score / weak-area breakdown.
- [ ] A file-reference integrity check validates every cited path against the
      PR's changed-file set.
- [ ] Tests cover create/read/update, answer/score storage, and the integrity
      check, including a review with an unresolvable reference.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

Mirror the `stack_explanations` data-access pattern. The integrity check is
reused at integration time to guard project-tied output (PRD FR-4).
