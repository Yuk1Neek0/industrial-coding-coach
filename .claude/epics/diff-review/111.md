# Task: PR fetching in the M11 GitHub client + change model + tests

## Description

Extend the shipped M11 GitHub client (`packages/db/src/github`) with pull
request fetching, and build a typed change model the review call reasons over:
changed files, hunks, additions/deletions, and the linked issue's acceptance
criteria where present.

## Acceptance Criteria
- [ ] PR-fetching added to the existing GitHub client, reusing its
      authentication and access path (ADR 0009) — no second GitHub access path.
- [ ] Fetches a PR's diff/patch, changed-file list, and linked issue where one
      exists.
- [ ] A typed change model: changed files, hunks, additions/deletions, linked
      issue acceptance criteria.
- [ ] Tested with mocked GitHub responses — no live API calls in CI.
- [ ] Graceful handling of a very large PR and a PR with no linked issue.
- [ ] `pnpm typecheck` and `pnpm test` pass.

## Technical Details

Add PR endpoints to the existing client module rather than creating a new one.
The change model is the input contract for the review call (task 003).

## Dependencies
- M11 GitHub client and ADR 0009 access path (shipped).
