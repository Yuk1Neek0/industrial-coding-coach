# Architecture Decision Records

ADRs record decisions that affect architecture, tooling, or workflow.

- File naming: `NNNN-short-title.md` (zero-padded sequence).
- Each ADR states: Status, Context, Decision, Consequences.
- Status values: Proposed | Accepted | Superseded by NNNN | Deprecated.
