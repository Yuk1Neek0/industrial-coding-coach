# Product Overview — where we are now

One-page snapshot of the product as defined in Milestone 1. Authoritative
source: `.claude/prds/product.md`.

## What it is

**Industrial Coding Coach** — a learning coach for AI-assisted code. It takes a
project the user already built with heavy AI assistance and coaches them to
genuinely understand it: the stack, the architecture, and how it maps onto a
real professional development workflow.

It does **not** generate projects. It coaches existing repos.

## How it runs

Open-source (MIT), local-first, and fully web-based: the user runs it on their
own machine and works entirely in the browser — no external IDE or extension.
Their code is analyzed locally. A GitHub account can optionally be connected
(read-only) to import a repo.

## Who it's for

**Job-seeking junior developers** — bootcamp grads and self-taught devs who
built AI-assisted ("vibe-coded") projects and cannot yet explain them.

## The problem

1. **"I can't explain my own project."** Freezes in interviews and reviews.
2. **"I don't understand the stack."** The technology is a black box — can't
   say why these tools, what they do, or what each part is for.

## Positioning

- Coaches **existing repos** — not a generator.
- Teaches **understanding**, not generation (vs. CCPM / BMAD / create-next-app).
- Produces **job-market artifacts** — interview Q&A, résumé bullets, architecture
  explanations.
- **Comprehension-checked** — every step has an understanding check; not a
  passive tutorial.
- **Visualizes the industrial development workflow in real time** — so users see
  how real-world software is built, not just how to prompt an AI.

## Success metric

The user **ships a portfolio project they fully understand and can defend** —
passing its comprehension checks and able to walk through it end to end.
