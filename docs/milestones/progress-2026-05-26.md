## M9 — Debug & Expansion Challenge System

Epic issue: [#139](https://github.com/Yuk1Neek0/industrial-coding-coach/issues/139) ·
PRD: `.claude/prds/debug-expansion-challenge.md` ·
Epic: `.claude/epics/debug-expansion-challenge/epic.md`

Two bounded Anthropic SDK calls produce and grade project-tied debug and
expansion challenges scoped strictly to files named in the M6 project map.
The generation call is lazy-per-type and cached per snapshot in the
`challenges` table; the grading call scores the user's **explanation only**

rejects any output referencing files outside the project map. Four UIs are
